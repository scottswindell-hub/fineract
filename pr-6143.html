Before and after

The essential domain change is a second, independent state dimension—not a new terminal loan status.

Before PR 6143

  • Working Capital Loan is ACTIVE.
  • Repayments and charges follow normal accounting.
  • No operation can establish charge-off state.
→

After PR 6143

  • Loan stays ACTIVE while chargedOff = true.
  • Repayment remains allowed but changes ledger destination.
  • New charges are rejected after charge-off.
  • The tag survives full repayment and only undo clears it.
